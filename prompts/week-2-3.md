## 2. Verified facts about ESAKE (checked 2026-09-24; do not re-discover, do verify in tests)
- Results: `GET https://www.esake.gr/el/action/EsakeResults?idchampionship={SEASON}&idteam=&idseason={PHASE}&series={RR}` → server-rendered HTML, one round per page.
  - Season IDs (hex): 2018-19 `A12E05CD`, 2019-20 `49EEB365`, 2020-21 `03FFA3AC`, 2021-22 `8C367D67`, 2022-23 `DC917125`, 2023-24 `C1AF5EF5`, 2024-25 `4820C134`, 2025-26 `44B80BEB`, 2026-27 `184645B9` (not yet in the dropdown; the URL works).
  - Phases: `00000001` = Α Φάση (regular season), `00000002` = Β Φάση (2025-26: contains the playoffs; round titles like `QF1`). **Formats differ by season** — verify each season's phases.
  - The `series` dropdown is **empty** in the HTML: enumerate `series=01, 02, …` until a page has no games (`series=40` → 0 games). Round title is an `<h5>` (`01η Αγωνιστική`, `QF1`).
  - Each game block: `idgame` hex (in `EsakegameView?idgame=…` links), date/time as **Athens local time without a year** (`Σαβ 4 Οκτ - 16:00`; the year comes from the month header `Οκτώβριος 2025`), venue, TV, home and away display names, score `85 - 87`, team IDs only via logo paths `/dat/esaketeam/{TEAM_ID}/…`.
  - Team IDs are stable across seasons while display names follow the *current* sponsor name (Panathinaikos = `00000001`, Olympiacos = `00000002`) → use IDs as keys.
  - 2025-26 round 1 had 6 games (13 teams); 2018-19 round 1 had 7.
- Box score: `EsakegameView?idgame={ID}&mode=3` → HTML tables per team: player, `P, 2PM-A, 3PM-A, FTM-A, REBS, D.REBS, O.REBS, AST, BLK, BLK-A, FOULS F, FOULS M, STL, TO, TIM.PL. (hh:mm:ss), RANK` + a team/bench row. **Verified complete for 2018-19** (game `F26689D1`, PAOK 81–64 Rethymno).
- PBP: see `docs/spikes/gbl-pbp.md` (works via plain HTTP for 2025-26 and 2018-19). **Not in scope this phase** beyond keeping the finding.
- Unverified (verify and record in tests/docs): unplayed-game markup (no score? `0 - 0`?), postponed games, forfeits, 2019-20 (cancelled mid-season) and 2020-21 phases, overtime marking.

## 3. Deliverables

### D1 — GBL results ingestion (`eurohoops ingest --competition gbl`)
- `--competition {euroleague,gbl}` (default `euroleague`, so the weeks 0–1 commands keep working). GBL default seasons = D-a.
- Raw cache `data/raw/gbl/results/{SEASON}/{PHASE}/{RR}.html.gz`; same existence-check semantics as EL.
- Parse into a typed GBL `games` table with the **same columns and pandera schema** as EL (`game_id` = hex idgame, `home`/`away` = ESAKE team IDs, `tipoff_utc` converted from Europe/Athens with `zoneinfo`, `phase` mapped to the allowed set with the raw round title kept in a `round_label` column, `neutral` = False unless a season's format says otherwise). Extend the schema only where GBL needs it, and justify each change.
- A `teams` lookup (team ID → latest display name) for the page.

### D2 — GBL box scores (`eurohoops ingest --competition gbl --details`)
- Box scores (`mode=3`) for completed games only, local backfill, not in CI.
- Parse to a `player_box` table (one row per player-game) with a pandera contract **and invariants**: Σ player points = team score from the results page; FGM ≤ FGA per type; minutes per team = 200 (+25 per OT) within ±1 min. Games failing a check are **flagged in a report, not dropped** (PLAN §4.4).

### D3 — EuroLeague backfill
- `eurohoops ingest --seasons 2007 … 2026` fetches the missing schedules (16 requests); `--details` backfills detail JSON (long-running, local only; document the expected duration).
- Apply D-e. The live EL model stays per D-c.

### D4 — DuckDB marts (`eurohoops build`)
- `sql/` holds the staging → marts transforms; `eurohoops build` materialises `data/marts/eurohoops.duckdb` with `games` (both competitions, `competition` column) and `player_box` (GBL; EL from the cached Boxscore JSON if it fits the same contract — otherwise GBL only, and say why).
- `backtest`, `predict` and `score` read games from the mart (so DuckDB earns its place). Contracts run as part of `build` and fail it on schema violations.

### D5 — GBL Elo backtest (`eurohoops backtest --competition gbl`)
- Reuse `models/elo.py` and the weeks 0–1 backtest (generalise the season splits via config, not copy-paste). Splits = D-b; grid ≤ 60; paired bootstrap CI vs B0.
- Report `reports/backtest_elo_gbl.json`. **Primary GBL metric: margin MAE** (PLAN §5: lopsided games make win-prob log loss less informative); still report log loss, Brier, accuracy.
- Note 2019-20 (cancelled) and 2020-21 (no fans) in the report; do not special-case them in the model this phase.

### D6 — GBL live log + daily workflow
- `eurohoops predict --competition gbl` → `predictions/gbl_2026-27.csv`, same columns and the same append-only/idempotent/refuse-if-late rules. `eurohoops score --competition gbl` → `reports/live_scorecard_gbl.json`.
- Extend `daily.yml`: EL steps unchanged, then GBL ingest (current season only) → predict → score; one commit if anything changed. GBL games are mostly weekend afternoons (Athens), so check that the 08:00 UTC run + 36 h window covers Saturday and Sunday games, and state the evidence.

### D7 — Minimal predictions page (`eurohoops publish`)
- Generates `site/index.html` from the prediction logs + scorecards: upcoming games per competition (teams, tip-off in Athens time, p_home, expected margin), last-round results vs predictions, and the running scorecard vs B0. Plain HTML + CSS, stdlib templating, **no new dependencies**, readable on a phone.
- Workflow `pages.yml` deploys `site/` to GitHub Pages after the daily job (`actions/upload-pages-artifact` + `actions/deploy-pages`). The page states clearly that the forecasts are a model benchmark, not betting advice (PLAN §1.3).

### D8 — Docs + session log

- Append the session entry to `memory.md`.

## 4. Required tests (no network; trimmed recorded fixtures)
1. **GBL parser:** a recorded round page parses to the expected rows; Athens → UTC conversion is correct on both sides of a DST change (late October and late March); the year comes from the month header across a December → January boundary.

6. **Log integrity:** both logs; a GBL run never touches `euroleague_2026-27.csv` bytes.
7. **Page:** `publish` output contains every logged upcoming game and escapes team names (Greek text, `&`).
- Coverage ≥ 85% on `src/eurohoops`.
